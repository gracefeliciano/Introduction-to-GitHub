# Student Grade Calculator
This repository contains a simple PHP project created as a sample project for learning GitHub and version control.

# Project Description/purpose
The student grade calculator allows users to enter a student's name and three grades and in response, it calculates the avarage grade and displays whether the student passed or failed.
